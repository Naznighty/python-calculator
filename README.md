# 🧮 Python Calculator

A simple scientific calculator built with Python and Tkinter.

## ✨ Features

- Basic arithmetic: `+` `-` `*` `/`
- Scientific functions: `sin`, `cos`, `√` (square root), `x²` (square)
- Clean GUI with a purple/pink color theme

## 🚀 How to Run

```bash
python calculator.py
```

> No extra installation needed — only Python 3 is required.

## 🖱️ Usage

| Button | Action |
|--------|--------|
| `0–9` | Enter digits |
| `+ - * /` | Arithmetic operators |
| `sin` / `cos` | Trig functions (input in degrees) |
| `√` | Square root |
| `x²` | Square the number |
| `=` | Calculate result |
| `c` | Clear display |
